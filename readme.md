
# Curso de Vue.js 3 - De Cero a Experto 🚀


>[!Note]
>Este es un curso gratis de VueJs, apoya al repositorio


Este repositorio contiene todos los proyectos desarrollados a lo largo del curso completo de Vue.js 3, desde los fundamentos hasta conceptos avanzados como TypeScript, Firebase, Pinia, pruebas unitarias y despliegue. Cada carpeta representa una sección del curso con ejemplos prácticos y explicaciones claras.



## 🧠 Lo que aprenderás

- Fundamentos de Vue 3 y la Composition API
- Creación de componentes reutilizables
- Uso de directivas como `v-if`, `v-for`, `v-model`, `v-bind`, entre otras
- Manejo de formularios y peticiones HTTP con Axios
- Diseño moderno con Tailwind CSS y Daisy UI
- Creación de PWAs (Progressive Web Apps)
- Integración con Firebase (Auth, Firestore, Storage)
- Gestión del estado global con Pinia
- Testing con Vitest
- Arquitectura limpia y buenas prácticas


## 📁 Estructura del repositorio

| Carpeta             | Descripción                                                                 |
|---------------------|-----------------------------------------------------------------------------|
| `01_fundamentos`    | Introducción a Vue 3, sintaxis básica y reactividad                         |
| `02_componentes`    | Componentes personalizados, props, slots y comunicación entre componentes   |
| `03_directivas`     | Uso de directivas como `v-if`, `v-for`, `v-show`, `v-model`, etc.           |
| `04_formularios`    | Validación de formularios, `v-model`, y eventos                             |
| `05_peticiones_http`| Peticiones con Axios, promesas, manejo de errores                           |
| `06_tailwind`       | Integración con Tailwind CSS y diseño responsivo                            |
| `07_criptocotizador`| Proyecto PWA para consultar criptomonedas                                   |
| `08_buscadorGifs`   | Buscador de GIFs usando la API de Giphy                                     |
| `09_typescript`     | Introducción a Vue con TypeScript                                           |
| `10_pinieaStore`    | Store global con Pinia y manejo avanzado de estados                         |
| `11_Instagram`      | Simulador completo de Instagram con Firebase y Vue Router                   |
| `12_testing`        | Pruebas unitarias de componentes y stores con Vitest                        |
